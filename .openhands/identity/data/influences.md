# Prior art, and what was taken from it

- **The Agent Client Protocol.** The runtime boundary this repository speaks
  across. Its gaps — no remaining quota, no reset time — are why usage has to
  be inferred from refusals rather than read.
- **The soul.md project** (https://github.com/aeonfun/soul.md): the identity
  document set and its load order — identity, voice, memory, examples, then
  raw data only when something needs grounding.
